## 1) 我读懂的现有流程是什么（从文件还原）

当前流程被描述为 3 个 skill 串联的“获取 → 分析 → 出报告”：

1. **insight**：把包含 `cdid` 列的文件上传到内网服务 `http://172.17.129.204:6829`，创建异步任务获取 **DNA/DAA 详情数据**，然后轮询任务状态；任务成功后通过 `oss_url` 下载结果文件。
2. **analyzer**：在本机调用 `~/.insight/bin/data_insight_analyzer`（文档称为 Go 编译的本地二进制）对详情数据做 **多发/碰撞/风险** 检测，输出一个包含多个 Sheet 的 Excel。
3. **report**：根据 analyzer 的分析结论，让模型输出一份**专业 HTML 报告**。

典型流程被写成：上传 CDID 列表 → insight 获取详情 → 下载结果 → analyzer 本地分析 → report 生成报告。

**证据**
- 三段式技能与典型流程：`xuqiu/README.md:3-10`
- insight 为内网异步任务 + 下载：`xuqiu/CLAUDE.md:60-68`、`xuqiu/gemini/insight/SKILL.md:106-136`、`xuqiu/gemini/insight/SKILL.md:142-143`
- analyzer 为本地二进制与三类检测：`xuqiu/CLAUDE.md:81-89`、`xuqiu/gemini/analyzer/SKILL.md:12-20`、`xuqiu/gemini/analyzer/SKILL.md:59-78`
- report 输出 HTML：`xuqiu/README.md:439-483`、`xuqiu/gemini/report/SKILL.md:8`

## 4) 如何跑 demo、如何跑真实流程（给出实际命令/入口 + 证据）

### 4.2 直接用 curl 走 insight（不依赖 AI CLI 的最小可执行入口）

insight skill 文档提供了创建任务的 curl 示例（multipart/form-data），以及查询列表/详情的接口说明。

**创建任务（文档示例）**
```bash
curl -X POST http://172.17.129.204:6829/api/statistical-analysis/v1/task/create \
  -F "name=测试任务" \
  -F "package_name=com.example.app" \
  -F "file=@./cdid_list.csv" \
  -F "message=dna" \
  -F "message=daa"
```

**查询任务详情（获取 status / oss_url）**
```bash
curl "http://172.17.129.204:6829/api/statistical-analysis/v1/task/detail?task_id=1234567890"
```

**证据**
- `/task/create` 接口与 curl 示例：`xuqiu/gemini/insight/SKILL.md:27-58`
- `/task/detail` 接口与返回包含 `status`、`oss_url`：`xuqiu/gemini/insight/SKILL.md:106-136`

> 注意（文档内不一致，未确认）：创建任务参数表写了 `start/end` 为必填，但 curl 示例未包含。见 `xuqiu/gemini/insight/SKILL.md:35-44` vs `xuqiu/gemini/insight/SKILL.md:45-53`。
