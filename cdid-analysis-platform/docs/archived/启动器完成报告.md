## 📦 使用内置 Gemini Skill

### 为什么使用内置 skill？

1. **无需手动部署** - report skill 已内置
2. **官方支持** - Gemini 官方维护
3. **功能完整** - 支持 HTML 报告生成
4. **快速启动** - 跳过 skill 部署步骤

### 内置 skill 详情

- **名称**: `report`
- **描述**: 根据 analyzer 输出的结果，生成一份数据分析报告
- **位置**: `~/.gemini/skills/report/SKILL.md`
- **功能**: 基于 JSON 数据生成专业的 HTML 报告

### 配置更新

已自动更新 `config/config.yaml`：

```yaml
gemini:
  cli_path: "gemini"
  skill_name: "report"        # 使用内置 skill
  skill_path: "built-in"      # 标记为内置
  timeout: 300
```

## 🐛 故障排除

### 常见问题和解决方案

#### 1. 端口被占用

**症状**：
```
⚠️  发现进程 PID xxxxx 占用端口 8000
```

**解决**：
- 启动器会自动清理
- 或选择菜单项 `6. 强制清理端口`

#### 2. Gemini CLI 未找到

**症状**：
```
❌ Gemini CLI 未找到
```

**解决**：
```bash
npm install -g @google/generative-ai-cli
```

#### 3. Python 版本警告

**症状**：
```
⚠️  Python 版本: 3.9.6 (推荐 3.11+)
```

**说明**：
- 可以继续使用（已兼容 3.9）
- 推荐升级到 3.11+ 以获得最佳性能

#### 4. 依赖安装失败

**解决**：
```bash
# 激活虚拟环境
source venv/bin/activate

# 手动安装
pip install -r requirements.txt
```
