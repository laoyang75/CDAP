# CDID 数据分析平台 - 测试指南

## 准备工作

### 1. 启动服务

使用启动器一键启动所有服务：

```bash
./run.sh
```

或

```bash
python3 launcher.py
```

在启动器菜单中选择：
- 输入 `1` - 启动服务
- 等待浏览器自动打开

### 2. 准备测试数据

系统已包含测试数据：`xuqiu/demo/波克问题数据.csv`

这个文件包含 23 条 CDID 数据，用于测试多发检测功能。

---

## 测试流程

### 第一步：创建任务

1. 访问首页：http://localhost:8000
2. 填写任务信息：
   - **任务名称**：测试多发检测
   - **包名**：com.boyaa.poker
   - **开始日期**：2026-01-01
   - **结束日期**：2026-01-07
   - **消息类型**：dna,daa
3. **上传文件**：选择 `xuqiu/demo/波克问题数据.csv`
4. **提交任务**

### 第二步：查看任务进度

提交后会自动跳转到任务详情页，可以看到：

- **实时进度条**
- **当前状态**：
  - queued（排队中）
  - fetching_data（获取数据中）
  - analyzing（分析中）
  - generating_report（生成报告中）
  - completed（已完成）

任务详情页会每 3 秒自动刷新状态。

### 第三步：下载报告

当任务状态变为 `completed` 后：

1. 页面上会显示"报告已生成"
2. 点击"下载报告"按钮
3. 浏览器会打开 HTML 报告
4. 报告包含：
   - 执行摘要
   - 数据统计
   - 多发检测结果
   - 可视化图表
   - 建议措施

## 常见问题

### Q1: 任务一直处于 queued 状态？

**检查**：
- Worker 是否正常运行
- 查看 Worker 日志：`tail -f logs/worker.log`

### Q2: 报告生成失败？

**检查**：
- Gemini CLI 是否正常
- 运行：`gemini --version`
- 查看错误日志

### Q3: 无法访问内网 API？

**注意**：
- 当前配置使用内网 API：`http://172.17.129.204:6829`
- 如果无法访问内网，Worker 会报错
- 可以修改配置使用模拟数据（开发模式）

### Q4: 端口被占用？

**解决**：
- 在启动器中选择 `6. 强制清理端口`
- 或手动关闭占用进程

```
ratio = unique_did_count / unique_oaid_count
is_duofa = ratio > 2.0
```

## API 测试示例

### 创建任务

```bash
curl -X POST http://localhost:8000/api/jobs \
  -F "name=测试任务" \
  -F "package_name=com.test" \
  -F "start_date=2026-01-01" \
  -F "end_date=2026-01-07" \
  -F "message_types=dna,daa" \
  -F "file=@xuqiu/demo/波克问题数据.csv"
```

### 查询任务

```bash
curl http://localhost:8000/api/jobs/{job_id}
```

### 下载报告

```bash
curl http://localhost:8000/api/jobs/{job_id}/report -o report.html
```
