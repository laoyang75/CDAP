# 🚀 立即开始 - CDID 数据分析平台

## 第一步：运行启动器

```bash
./run.sh
```

或

```bash
python3 launcher.py
```

## 第二步：选择"启动服务"

在启动器菜单中输入：

```
1
```

启动器会自动完成：
- ✅ 检查 Python 环境
- ✅ 创建虚拟环境
- ✅ 安装所有依赖
- ✅ 配置 Gemini CLI
- ✅ 初始化数据库
- ✅ 清理端口占用
- ✅ 启动 API Server
- ✅ 启动 Worker
- ✅ 打开浏览器

## 第三步：使用系统

浏览器会自动打开：http://localhost:8000

### 创建测试任务

1. 填写任务信息
2. 上传测试文件：`xuqiu/demo/波克问题数据.csv`
3. 提交任务
4. 查看实时进度
5. 下载 HTML 报告

## 重要提示

### ✅ 已自动完成

- Gemini CLI 已检测到（版本 0.25.2）
- 内置 report skill 已配置
- 所有环境已自动安装

### ⚠️ 注意事项

1. **端口 8000** 必须可用（启动器会自动清理）
2. **Gemini CLI** 已安装无需手动配置
3. **内网 API** 如无法访问，部分功能会报错（可忽略）

## 启动器功能

```
1. 🚀 启动服务       - 一键启动所有服务
2. 🛑 停止服务       - 停止所有服务
3. 🔄 重启服务       - 重启所有服务
4. 🌐 打开浏览器     - 访问用户端
5. 📊 查看状态       - 查看服务状态
6. 💪 强制清理端口   - 解决端口锁死
7. 📝 查看日志       - 查看运行日志
0. 🚪 退出           - 退出启动器
```
