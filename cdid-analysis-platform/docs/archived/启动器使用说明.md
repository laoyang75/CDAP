# 启动器使用说明

## 快速启动

### macOS / Linux

```bash
./run.sh
```

或

```bash
python3 launcher.py
```

### Windows

双击运行 `run.bat` 或在命令行中执行：

```cmd
python launcher.py
```

---

## 功能说明

启动器提供了完整的服务管理功能：

### 1. 🚀 启动服务

- 自动检查并创建虚拟环境
- 自动安装依赖包
- 自动检查 Gemini CLI
- 自动配置 Gemini Skill（使用内置 report skill）
- 自动初始化数据库
- 自动清理端口占用
- 启动 API Server 和 Worker
- 自动打开浏览器访问 http://localhost:8000

### 2. 🛑 停止服务

- 优雅停止所有服务进程
- 清理 PID 文件

### 3. 🔄 重启服务

- 先停止，再启动
- 确保端口完全释放

### 4. 🌐 打开浏览器

- 快速打开用户端首页

### 5. 📊 查看状态

- 显示所有服务进程状态
- 显示端口占用情况

### 6. 💪 强制清理端口

- 强制关闭占用 8000 端口的进程
- 解决端口锁死问题

### 7. 📝 查看日志

- 查看 API Server 最新日志
- 查看 Worker 最新日志

### 0. 🚪 退出

- 退出启动器（不停止服务）

## 首次启动流程

1. **运行启动器**
   ```bash
   ./run.sh  # macOS/Linux
   # 或
   python launcher.py  # 所有平台
   ```

2. **环境检查**
   - 启动器会自动检查 Python 版本（需要 3.11+）
   - 检查虚拟环境，不存在则自动创建
   - 自动安装所有依赖（从 requirements.txt）

3. **Gemini CLI 检查**
   - 检查 Gemini CLI 是否安装
   - **如果未安装**，请手动安装：
     ```bash
     npm install -g @google/generative-ai-cli
     ```
   - 验证安装：
     ```bash
     gemini --version
     ```

4. **Skill 配置**
   - 启动器会自动检测 Gemini 内置的 `report` skill
   - 自动更新配置文件使用内置 skill

5. **数据库初始化**
   - 自动创建 SQLite 数据库
   - 创建所有必需的表

6. **选择操作**
   - 输入 `1` 启动服务
   - 等待服务启动完成
   - 浏览器自动打开 http://localhost:8000

## 故障排除

### 问题1：端口被占用

**现象**：
```
⚠️  发现进程 PID xxxxx 占用端口 8000
```

**解决**：
- 启动器会自动清理占用端口的进程
- 或手动选择 `6. 强制清理端口`

### 问题2：Gemini CLI 未安装

**现象**：
```
❌ Gemini CLI 未找到
请安装: npm install -g @google/generative-ai-cli
```

**解决**：
1. 安装 Node.js（如果未安装）
2. 运行：
   ```bash
   npm install -g @google/generative-ai-cli
   ```
3. 验证：
   ```bash
   gemini --version
   ```

### 问题3：Python 版本过低

**现象**：
```
❌ Python 版本过低: 3.9.x
需要 Python 3.11+
```

**解决**：
- 升级 Python 到 3.11 或更高版本
- macOS: `brew install python@3.11`
- Windows: 从 python.org 下载安装

### 问题4：依赖安装失败

**现象**：
```
❌ 依赖安装失败
```

**解决**：
1. 手动进入虚拟环境：
   ```bash
   source venv/bin/activate  # macOS/Linux
   venv\Scripts\activate     # Windows
   ```
2. 手动安装：
   ```bash
   pip install -r requirements.txt
   ```

### 问题5：服务启动超时

**现象**：
```
⚠️  服务启动超时，请检查日志
```

**解决**：
1. 选择 `7. 查看日志`
2. 检查错误信息
3. 常见原因：
   - 端口被占用
   - 依赖缺失
   - 配置文件错误

## 日志文件位置

- **API Server 日志**: `logs/api.log`
- **Worker 日志**: `logs/worker.log`
- **应用日志**: `logs/app.log`

查看实时日志：
```bash
# API Server
tail -f logs/api.log

# Worker
tail -f logs/worker.log
```

## 进程管理

启动器会在项目根目录创建 `.launcher.pid` 文件，记录所有服务进程的 PID。

**手动停止所有服务**：
```bash
# 读取 PID 并停止
cat .launcher.pid | xargs kill

# 强制停止
cat .launcher.pid | xargs kill -9
```

## 配置文件

启动器会读取并修改以下配置：

- **主配置**: `config/config.yaml`
  - Gemini CLI 路径
  - Skill 名称（自动设置为 `report`）
  - 端口配置
  - 数据库配置

## 高级用法

### 后台运行

如果你想让服务在后台运行而不使用启动器菜单：

```bash
# 直接启动服务
python launcher.py --start-only

# 或使用原始启动脚本
./dev.sh &
```

### Docker 部署

如果你需要在生产环境部署，推荐使用 Docker：

```bash
docker-compose up -d
```
