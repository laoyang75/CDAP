# CDID 数据分析平台 - 方案设计文档

**版本**: v0.1.0
**日期**: 2026-01-23
**目的**: 将 Gemini CLI 命令行流程包装成 Web 服务，降低使用门槛

---

## 1. 项目背景与目标

### 1.1 现状与痛点

**当前流程**（基于 Gemini CLI Skills）：
```
用户 → Gemini CLI → insight skill → analyzer skill → report skill → HTML 报告
```

**痛点**：
1. ❌ 必须懂命令行，技术门槛高
2. ❌ 需要手动配置 Gemini CLI（版本 >= v0.24.5，启用 skills）
3. ❌ 流程中有人工步骤（下载文件、本地分析）
4. ❌ 无法批量处理，无法追溯历史
5. ❌ 依赖 Go 二进制文件（analyzer），部署复杂

### 1.2 改造目标

**目标**：将命令行操作转化成 **Web 服务**，让任何人都能使用数据分析。

**新流程**：
```
用户浏览器 → Web UI → Python 后端 → 调用内网 API → Python 数据处理 → Gemini CLI 生成报告 → 返回 Web UI
```

**核心价值**：
- ✅ **零门槛**：浏览器上传文件，填表单即可
- ✅ **全自动**：后端自动调用 API、处理数据、生成报告
- ✅ **可追溯**：所有任务记录在数据库，可查询历史
- ✅ **可扩展**：方便添加新的 Python 分析模块、新的 Gemini skills
- ✅ **纯 Python**：无需 Go 二进制，部署简单

## 3. 详细流程设计

### 3.1 用户创建任务流程

```
[用户] 上传 CDID 文件 + 填写表单
   ↓
[Web UI] POST /jobs (multipart/form-data)
   ↓
[API Server]
   1. 验证参数（package_name、时间范围、数据类型）
   2. 保存上传文件到 jobs/{job_id}/input.csv
   3. 插入数据库 (status='queued')
   4. 返回 job_id
   ↓
[Worker] 从队列取任务 (status='queued')
   ↓
[阶段 1: Fetching] 调用内网 API 创建任务
   1. POST /api/statistical-analysis/v1/task/create
   2. 轮询查询状态 (每 30 秒)
   3. status='success' 后获取 oss_url
   4. 下载 Excel 到 jobs/{job_id}/raw_data.xlsx
   5. 更新数据库 (status='fetching', progress=XX%)
   ↓
[阶段 2: Analyzing] Python 数据分析
   1. 读取 raw_data.xlsx (Pandas)
   2. 执行多发检测 (duplicate)
   3. 执行碰撞检测 (impact)
   4. 执行风险检测 (risk)
   5. 生成分析结果 JSON (analysis_result.json)
   6. 更新数据库 (status='analyzing', progress=XX%)
   ↓
[阶段 3: Reporting] Gemini CLI 生成报告
   1. 准备 prompt + 分析结果
   2. 调用: cat analysis_result.json | gemini -p "根据以下数据生成专业HTML报告..."
   3. 保存 HTML 到 jobs/{job_id}/report.html
   4. 更新数据库 (status='done', report_path='...')
   ↓
[用户] GET /jobs/{id}/report 查看报告
```

### 3.2 状态机设计

```
状态流转：queued → fetching → analyzing → reporting → done
         ↓ (任意阶段失败)
       failed
```

| 状态 | 说明 | 可重试 |
|------|------|--------|
| `queued` | 已创建，等待处理 | - |
| `fetching` | 调用内网 API，获取数据 | ✅ (网络错误可重试) |
| `analyzing` | Python 数据分析 | ❌ (数据错误不可重试) |
| `reporting` | Gemini CLI 生成报告 | ✅ (LLM 可重试) |
| `done` | 完成 | - |
| `failed` | 失败（记录错误信息） | - |

### 4.3 Gemini CLI 调用（gemini_reporter.py）

**职责**：使用 Gemini CLI Headless Mode 生成 HTML 报告

**实现方式**：通过管道输入分析结果

```python
import subprocess
import json

class GeminiReporter:
    """Gemini CLI 报告生成器"""

    def generate_report(self, analysis_result: dict) -> str:
        """
        生成 HTML 报告

        输入: 分析结果 JSON
        输出: HTML 字符串
        """
        # 准备 prompt
        prompt = self._build_prompt()

        # 将分析结果转为 JSON
        result_json = json.dumps(analysis_result, ensure_ascii=False, indent=2)

        # 调用 Gemini CLI (管道输入)
        cmd = [
            "gemini",
            "-p", prompt
        ]

        process = subprocess.Popen(
            cmd,
            stdin=subprocess.PIPE,
            stdout=subprocess.PIPE,
            stderr=subprocess.PIPE,
            text=True
        )

        stdout, stderr = process.communicate(input=result_json)

        if process.returncode != 0:
            raise RuntimeError(f"Gemini CLI failed: {stderr}")

        return stdout  # HTML 报告

    def _build_prompt(self) -> str:
        """构建 prompt"""
        return """
你是一位专业的数据分析师。根据下面的 CDID 数据分析结果，生成一份专业的 HTML 格式分析报告。

要求：
1. 使用 HTML 格式输出（包含 <html>、<head>、<body> 标签）
2. 样式美观（可内联 CSS 或使用 Bootstrap CDN）
3. 结构清晰：执行摘要 → 多发检测 → 碰撞检测 → 风险检测 → 结论建议
4. 重点突出：用颜色标记高风险项（红色）、中风险（黄色）
5. 可视化：如有必要，用简单的 HTML 表格或 chart.js 图表
6. 专业术语：使用业务语言，避免技术黑话

输入数据（JSON 格式）将通过管道传入。请直接输出完整的 HTML 代码，不要添加任何解释。
"""
```

**调用示例**（命令行等效）：

```bash
cat analysis_result.json | gemini -p "根据以下数据生成专业HTML报告..."
```

### 4.4 Worker 任务处理（worker.py）

**职责**：后台任务处理器（FIFO 队列，单线程）

```python
import asyncio
from sqlalchemy.orm import Session

class Worker:
    """后台任务处理器（单线程 FIFO）"""

    def __init__(self, db: Session):
        self.db = db
        self.insight_client = InsightClient()
        self.analyzer = DataAnalyzer()
        self.reporter = GeminiReporter()

    async def run_forever(self):
        """主循环：FIFO 取任务"""
        while True:
            job = self.get_next_job()  # SELECT ... WHERE status='queued' ORDER BY created_at LIMIT 1

            if not job:
                await asyncio.sleep(5)
                continue

            try:
                await self.process_job(job)
            except Exception as e:
                self.mark_failed(job.id, str(e))

    async def process_job(self, job):
        """处理单个任务"""
        # 阶段 1: Fetching
        self.update_status(job.id, 'fetching', progress=10)
        task_id = await self.insight_client.create_task(...)

        # 轮询等待
        while True:
            status = await self.insight_client.query_task_status(task_id)
            if status['status'] == 'success':
                break
            await asyncio.sleep(30)

        # 下载数据
        await self.insight_client.download_result(
            status['oss_url'],
            f'jobs/{job.id}/raw_data.xlsx'
        )

        # 阶段 2: Analyzing
        self.update_status(job.id, 'analyzing', progress=50)
        analysis_result = self.analyzer.analyze(f'jobs/{job.id}/raw_data.xlsx')

        # 保存分析结果
        with open(f'jobs/{job.id}/analysis_result.json', 'w') as f:
            json.dump(analysis_result, f, ensure_ascii=False, indent=2)

        # 阶段 3: Reporting
        self.update_status(job.id, 'reporting', progress=80)
        html_report = self.reporter.generate_report(analysis_result)

        # 保存报告
        with open(f'jobs/{job.id}/report.html', 'w') as f:
            f.write(html_report)

        # 完成
        self.update_status(job.id, 'done', progress=100, report_path=f'jobs/{job.id}/report.html')
```

### 12.2 异步轮询内网 API

**挑战**：内网 API 是异步任务，需要轮询等待

**解决方案**：

```python
async def wait_for_task(task_id: str, timeout: int = 1800):
    """轮询等待任务完成（最多 30 分钟）"""
    start_time = time.time()

    while time.time() - start_time < timeout:
        status = await insight_client.query_task_status(task_id)

        if status['status'] == 'success':
            return status
        elif status['status'] == 'failed':
            raise RuntimeError("内网任务失败")

        await asyncio.sleep(30)  # 每 30 秒查询一次

    raise TimeoutError("任务超时")
```

### 12.3 数据分析算法简化

**多发检测**（示例）：

```python
def _detect_duplicate(self, df: pd.DataFrame) -> list:
    """多发检测：检测重复的设备指纹"""
    # 按设备指纹（did, oaid, imei）分组
    groups = df.groupby(['did', 'oaid', 'imei'])['cdid'].apply(list)

    # 筛选出重复的组（cdid 数量 > 1）
    duplicates = groups[groups.apply(len) > 1]

    results = []
    for idx, (fingerprint, cdid_list) in enumerate(duplicates.items()):
        results.append({
            "group_id": idx + 1,
            "cdid_list": cdid_list,
            "fingerprint": dict(zip(['did', 'oaid', 'imei'], fingerprint))
        })

    return results
```
