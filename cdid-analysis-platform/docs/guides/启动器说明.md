# 启动器使用说明

## 🎯 推荐使用：Web 启动器

由于 macOS tkinter 兼容性问题，**强烈推荐使用 Web 版启动器**。

### 🚀 快速启动

```bash
./run_web.sh
```

或

```bash
source venv/bin/activate
python3 launcher_web.py
```

启动后会自动打开浏览器，访问地址：**http://localhost:5555**

---

## 📱 三种启动器对比

| 启动器 | 适用场景 | 优点 | 缺点 |
|--------|---------|------|------|
| **Web 启动器** | **推荐** ✅ | 美观、兼容性好、功能完整 | 需要额外端口 5555 |
| 命令行启动器 | 服务器环境 | 轻量、快速 | 无图形界面 |
| GUI 启动器 | macOS 26+ | 原生界面 | ⚠️ 旧系统不兼容 |

---

## 🌐 Web 启动器功能

### 主要功能

1. **🚀 启动服务** - 一键启动 API Server 和 Worker
2. **🛑 停止服务** - 优雅停止所有服务
3. **🔄 重启服务** - 快速重启
4. **🌐 打开浏览器** - 打开主应用 (http://localhost:8000)
5. **🔍 检查环境** - 验证 Python、虚拟环境、Gemini CLI
6. **💪 清理端口** - 强制清理端口 8000

### 实时监控

- **服务状态**：实时显示 API Server、Worker、端口状态
- **运行日志**：彩色日志，自动滚动
- **进度条**：操作进度可视化

## 🛠️ 其他启动方式

### 1. 命令行启动器

```bash
python3 launcher.py
```

然后按提示选择：
- `1` - 启动服务
- `2` - 停止服务
- `3` - 重启服务
- `4` - 打开浏览器
- `5` - 查看状态
- `6` - 强制清理端口
- `7` - 查看日志
- `0` - 退出

### 2. GUI 启动器（仅限 macOS 26+）

```bash
python3 launcher_gui.py
```

**注意**：如果遇到以下错误：
```
macOS 26 (2602) or later required, have instead 16 (1602) !
Abort trap: 6
```

说明您的系统 tkinter 版本不兼容，请使用 **Web 启动器**。

### 3. 直接启动（开发模式）

```bash
./dev.sh
```

## 📊 端口说明

- **8000** - 主应用端口（API Server + 用户界面）
- **5555** - Web 启动器端口（仅启动器界面）

## ❓ 常见问题

### Q1: Web 启动器无法打开？

**检查端口占用**：
```bash
lsof -ti:5555
```

如果端口被占用，清理后重试：
```bash
lsof -ti:5555 | xargs kill -9
```

### Q2: 服务启动失败？

1. **检查日志**：
   ```bash
   tail -f logs/api.log
   tail -f logs/worker.log
   ```

2. **运行诊断**：
   ```bash
   python3 diagnose.py
   ```

3. **清理端口**：
   在 Web 启动器中点击 "💪 清理端口"

### Q3: 页面加载慢？

**✅ 此问题已解决！**

最新版本已将所有 Bootstrap 资源下载到本地，页面加载时间 < 200ms。

详见：`性能优化报告.md`

### Q4: 如何关闭所有服务？

**方法 1**：使用 Web 启动器
- 访问 http://localhost:5555
- 点击 "🛑 停止服务"

**方法 2**：使用命令
```bash
pkill -f "uvicorn src.api.main:app"
pkill -f "src.worker.main"
```

## 🎯 推荐工作流

### 日常使用

1. **启动 Web 启动器**
   ```bash
   ./run_web.sh
   ```

2. **在浏览器中管理服务**
   - 自动打开 http://localhost:5555
   - 点击 "🚀 启动服务"
   - 点击 "🌐 打开浏览器" 访问主应用

3. **完成工作后**
   - 点击 "🛑 停止服务"
   - 关闭 Web 启动器（Ctrl+C）

### 开发调试

1. **直接启动服务**
   ```bash
   ./dev.sh
   ```

2. **查看实时日志**
   ```bash
   tail -f logs/api.log
   tail -f logs/worker.log
   ```

3. **运行诊断**
   ```bash
   python3 diagnose.py
   ```
