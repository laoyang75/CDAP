# 🚀 快速启动指南

---

## ⭐ 推荐启动方式

### 使用 Web 启动器

```bash
./run_web.sh
```

**就这么简单！** 🎉

启动后浏览器会自动打开 http://localhost:5555

---

## 📋 启动后的操作

在 Web 界面中（http://localhost:5555）：

1. **点击 "🚀 启动服务"**
   - 等待 10-15 秒
   - 看到 "✓ 服务启动成功" 提示

2. **打开应用**：
   - **🌐 打开用户端** - 创建任务、查看任务列表（http://localhost:8000）
   - **🔐 打开管理后台** - 用户管理、配置管理（http://localhost:8000/admin）

3. **完成后点击 "🛑 停止服务"**

---

## ❌ 请勿使用

以下命令会导致崩溃，**请不要运行**：

```bash
# ❌ 会崩溃
python3 launcher_gui.py

# ❌ 会崩溃
./run_gui.sh  # 已重定向到 Web 启动器
```

**原因**: tkinter 版本不兼容

## 🛠️ 其他启动方式

### 方式 1: 命令行启动器

```bash
python3 launcher.py
```

然后输入 `1` 启动服务

### 方式 2: 直接启动

```bash
./dev.sh
```

服务在前台运行，Ctrl+C 停止

## ❓ 常见问题

### Q: 启动器无法打开？

```bash
# 检查端口占用
lsof -ti:5555

# 清理端口
lsof -ti:5555 | xargs kill -9

# 重新启动
./run_web.sh
```

### Q: 服务启动失败？

1. 查看日志：`tail -f logs/api.log`
2. 运行诊断：`python3 diagnose.py`
3. 在 Web 界面点击 "💪 清理端口"
