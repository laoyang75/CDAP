## 🔄 版本变更

### v0.2.0（2026-01-23）

**基于 UI 确认的重大更新**：

1. **核心概念变化**：
   - 引入"管线"概念（Pipeline = Python 脚本 + Gemini Skill）
   - 一个任务只执行一条管线
   - 管线失败后可手动重新运行

2. **新增功能**：
   - ✅ 客户配置：管理客户-包名映射关系
   - ✅ 脚本编辑：编辑 Python 脚本并配置/引用 Gemini Skill（导入走人工）
   - ✅ 数据下载：用户可下载原始数据（Excel）

3. **UI 优化**：
   - ✅ 创建任务页：客户名称检索 + 自动填充包名
   - ✅ 任务详情页：增加下载原始数据按钮
   - ✅ 后台管理：增加客户配置页面
   - ✅ 后台管理：脚本编辑页面改为配置/引用 Skill（不支持新建；导入走人工）

4. **技术细节明确**：
   - ✅ Python 脚本标准接口：`def analyze(input_file, user_info, start_date, end_date) -> dict`
   - ✅ Gemini CLI 调用方式：`cat result.json | gemini -p "@<skill_name> 生成HTML报告"`（或直接用位置参数替代 `-p`）
   - ✅ 管线配置：脚本目录 + 脚本文件名 + Skill 名称
