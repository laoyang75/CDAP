## 🔍 问题 1: GUI 启动器 tkinter 兼容性错误（严重崩溃）⚠️

### 错误信息

```
macOS 26 (2602) or later required, have instead 16 (1602) !
Abort trap: 6
```

**后续崩溃报告**（用户再次尝试运行后）：

```
Exception Type:    EXC_CRASH (SIGABRT)
Exception Codes:   0x0000000000000000, 0x0000000000000000
Termination Reason:  Namespace SIGNAL, Code 6, Abort trap: 6

Application Specific Information:
abort() called

4   Tk     0x2448e4730 TkpInit + 452
```

### 根本原因

系统自带的 Python tkinter 库版本太旧（Tk 8.5.9 from 2010），与当前 macOS 不兼容。

Tk 库在初始化时（`TkpInit` 函数）检测到版本不匹配，主动调用 `abort()` 终止程序，导致系统崩溃。

### 解决方案

创建了 **Web 版启动器** (`launcher_web.py`)，完全替代 tkinter，使用 Flask 提供 Web 界面。

### 优势

- ✅ **无依赖问题**: 基于 Flask，不依赖系统 tkinter
- ✅ **更美观**: 现代化渐变色 UI 设计
- ✅ **更强大**: 实时状态刷新，彩色日志
- ✅ **跨平台**: 兼容所有系统（macOS, Linux, Windows）

## 🔍 问题 2: 页面加载很慢

### 用户反馈

> "启动后打开页面很慢，一直在加载我不知道什么原因"

### 诊断过程

1. **测试服务启动时间**: ✅ 仅需 1 秒
2. **测试后端性能**: ✅ API 响应 < 20ms
3. **测试静态资源**: ❌ **发现问题！**

### 问题根源

所有 8 个 HTML 模板都从**外部 CDN** 加载 Bootstrap 资源：

- `https://cdn.jsdelivr.net/npm/bootstrap@5.3.0/...`
- `https://cdn.jsdelivr.net/npm/bootstrap-icons@1.11.0/...`

总共约 **563 KB** 的资源需要从国外 CDN 加载。

### 解决方案

1. **下载所有资源到本地**:
   ```
   src/ui/static/
   ├── css/bootstrap.min.css (227 KB)
   ├── css/bootstrap-icons.min.css (84 KB)
   ├── css/fonts/ (字体 300 KB)
   └── js/bootstrap.bundle.min.js (80 KB)
   ```

2. **更新所有 8 个模板**: 将 CDN 链接改为本地路径

3. **重启服务**: 应用新配置

### 优化效果

**修改前**:
- 页面加载: 取决于网络（可能很慢或超时）

**修改后**:
```
✅ 主页: 0.016 秒
✅ Bootstrap CSS: 0.010 秒
✅ Bootstrap JS: 0.002 秒
✅ Bootstrap Icons: 0.003 秒
```

**总加载时间**: < 200ms ⚡

## 🔍 问题 3: launcher_gui.py 代码警告

### 警告信息

```
launcher_gui.py:267:37 "process_type" 未使用
```

### 问题

`check_process_running(self, process_type)` 方法接受参数但未使用。

### 修复

重新实现该方法，根据 `process_type` 区分检查 API Server 或 Worker：

```python
def check_process_running(self, process_type):
    if process_type == 'api':
        result = subprocess.run(['pgrep', '-f', 'uvicorn src.api.main:app'], ...)
        return result.returncode == 0
    elif process_type == 'worker':
        result = subprocess.run(['pgrep', '-f', 'src.worker.main'], ...)
        return result.returncode == 0
```
