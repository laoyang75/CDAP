`raw_data.xlsx` 解析约定（标准）
数据来自内网下载的 `raw_data.xlsx`。
常见列名为“带中文说明”的形式，例如：
sys__boot__id(系统启动 ID), android_id(ANDROID_ID), did(设备主 ID（DID）), oaid(设备 OAID), cdid(客户设备 ID（CDID）)
脚本建议统一用：
sys__boot__id / android_id / did / oaid / cdid
读取入口：src.worker.data_formats.insight_excel（负责列名标准化，其它字段不改名）。
若 xlsx 分 `dna/daa` 两个 sheet，系统会合并数据并自动补充 message_type 列（dna/daa）。
若上游字段名新增/变更导致脚本报“缺少字段”，优先在 config/column_mapping.yaml 增加别名映射（修改后重启生效）。
