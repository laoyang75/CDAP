# 如何测试任务创建

---

## 📋 前提条件

1. **服务已启动**：
   ```bash
   ./run_web.sh
   ```
   在 Web 启动器中点击 "🚀 启动服务"

2. **准备测试数据**：
   需要一个 CSV 或 XLSX 文件（测试用）

---

## 🧪 测试步骤

### 方法 1: 通过 Web 界面（推荐）

1. **打开用户端**：
   - 在 Web 启动器中点击 "🌐 打开用户端"
   - 或直接访问：http://localhost:8000

2. **填写任务信息**：
   - **任务名称**：测试任务
   - **包名**：com.example.test
   - **上传文件**：选择一个 CSV 或 XLSX 文件
   - **开始日期**：默认（最近7天）
   - **结束日期**：默认（今天）
   - **数据类型**：勾选 DNA 或 DAA

3. **提交任务**：
   - 点击 "创建任务" 按钮
   - 看到 "创建中..." 加载状态
   - 等待提交完成

4. **验证结果**：
   - ✅ 应该自动跳转到任务详情页
   - ✅ URL 应该是：`http://localhost:8000/tasks/{任务ID}`
   - ✅ 页面显示任务信息和进度

**如果出现错误**：
- 检查浏览器控制台（F12 → Console）
- 查看 API 日志：`tail -f logs/api.log`

---

### 方法 2: 通过 API（高级）

使用 curl 测试 API：

```bash
# 准备测试文件
echo "did,oaid,timestamp" > test.csv
echo "device1,oaid1,2024-01-01" >> test.csv
echo "device2,oaid2,2024-01-02" >> test.csv

# 创建任务
curl -X POST http://localhost:8000/api/jobs \
  -F "name=测试任务" \
  -F "package_name=com.example.test" \
  -F "start_date=2024-01-01" \
  -F "end_date=2024-01-31" \
  -F "message_types=dna,daa" \
  -F "file=@test.csv"
```

**预期响应**：
```json
{
  "id": "01JXXXXXXXXXXXXXXXXXX",
  "name": "测试任务",
  "package_name": "com.example.test",
  "status": "queued",
  "progress": 0,
  "progress_message": "任务已创建，等待处理",
  ...
}
```

然后访问任务详情：
```bash
# 使用返回的 ID
curl http://localhost:8000/tasks/01JXXXXXXXXXXXXXXXXXX
```

## ❓ 常见问题

### Q1: 提交后仍然显示 {"detail":"Not Found"}

**可能原因**：
1. 浏览器缓存了旧版本的 JavaScript
2. 服务未重启应用最新代码

**解决方案**：
```bash
# 1. 清除浏览器缓存
# Chrome: Cmd/Ctrl + Shift + R（硬刷新）

# 2. 重启服务
pkill -f "uvicorn src.api.main:app"
pkill -f "src.worker.main"

# 然后在 Web 启动器中点击 "🚀 启动服务"
```

### Q2: 文件上传失败

**检查**：
1. 文件格式是否为 CSV 或 XLSX
2. 文件大小是否超过限制（默认 50MB）
3. 文件是否可读

**查看错误**：
```bash
tail -f logs/api.log
```

### Q3: 任务创建后一直停在"排队中"

**可能原因**：
- Worker 未启动

**检查 Worker**：
```bash
# 查看 Worker 日志
tail -f logs/worker.log

# 检查 Worker 进程
ps aux | grep "src.worker.main"
```

**重启 Worker**：
```bash
pkill -f "src.worker.main"
source venv/bin/activate
python3 -m src.worker.main > logs/worker.log 2>&1 &
```

## 📊 预期的任务处理流程

1. **创建 (queued)** ← 您在这里
   - 任务提交成功
   - 进入队列等待处理

2. **处理中 (processing)**
   - Worker 开始处理
   - 调用 Insight API 获取数据
   - 执行多发检测算法

3. **生成报告 (generating_report)**
   - 使用 Gemini AI 生成报告
   - 报告包含分析结果和可视化

4. **完成 (completed)**
   - 任务处理完成
   - 可以下载报告

5. **失败 (failed)**
   - 如果处理出错
   - 查看错误信息
