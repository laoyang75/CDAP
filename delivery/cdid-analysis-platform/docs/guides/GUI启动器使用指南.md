# GUI 启动器使用指南

## 🎨 启动 GUI 启动器

### macOS / Linux

```bash
./run_gui.sh
```

或

```bash
python3 launcher_gui.py
```

### Windows

双击运行 `run_gui.bat` 或：

```cmd
python launcher_gui.py
```

## 功能按钮说明

### 1. 🚀 启动服务

**功能**：
- 自动检查并创建虚拟环境
- 自动安装依赖包
- 清理端口占用
- 启动 API Server
- 启动 Worker
- 初始化数据库
- 提示是否打开浏览器

**使用时机**：
- 首次使用
- 服务停止后需要重新启动

**耗时**：
- 首次启动：30-60 秒（需要安装依赖）
- 后续启动：5-15 秒

### 2. 🛑 停止服务

**功能**：
- 优雅停止所有服务进程
- 清理 PID 文件
- 释放端口

**使用时机**：
- 需要完全停止服务时
- 系统维护时

### 3. 🔄 重启服务

**功能**：
- 先停止所有服务
- 等待 2 秒
- 重新启动服务

**使用时机**：
- 修改代码后需要重新加载
- 服务出现问题时

### 4. 🌐 打开浏览器

**功能**：
- 打开默认浏览器
- 访问 http://localhost:8000

**使用时机**：
- 服务启动后访问用户端
- 需要重新打开页面时

### 5. 💪 清理端口

**功能**：
- 强制关闭占用端口 8000 的所有进程
- 解决端口锁死问题

**使用时机**：
- 端口被占用无法启动时
- 服务异常退出时

### 6. 🔍 检查环境

**功能**：
- 检查 Python 版本
- 检查虚拟环境
- 检查 Gemini CLI
- 检查端口状态

**使用时机**：
- 首次使用前
- 遇到启动问题时
- 环境配置检查

### 7. 📝 清空日志

**功能**：
- 清空日志显示区域

**使用时机**：
- 日志太多需要清理时

### 8. 📚 API 文档

**功能**：
- 打开 Swagger UI API 文档
- 访问 http://localhost:8000/docs

**使用时机**：
- 需要查看 API 接口时
- 测试 API 端点时

### 9. ❌ 退出

**功能**：
- 退出启动器
- 服务继续在后台运行

**注意**：
- 如果服务正在运行，会提示确认
- 退出启动器不会停止服务

## 状态指示说明

### 服务状态

- **● 未启动**（灰色）- 服务未运行
- **● 运行中**（绿色）- 服务正常运行
- **● 已占用**（橙色）- 端口被占用

### 日志颜色

- **黑色** - 普通信息
- **绿色** - 成功信息
- **橙色** - 警告信息
- **红色** - 错误信息

## 使用流程

### 首次启动

1. **运行 GUI 启动器**
   ```bash
   ./run_gui.sh
   ```

2. **检查环境**
   - 点击 `🔍 检查环境` 按钮
   - 查看日志输出
   - 确认所有环境正常

3. **启动服务**
   - 点击 `🚀 启动服务` 按钮
   - 观察进度条和日志
   - 等待启动完成

4. **打开浏览器**
   - 启动成功后会提示
   - 点击"是"自动打开浏览器
   - 或手动点击 `🌐 打开浏览器` 按钮

### 日常使用

1. **启动启动器**
2. **点击启动服务**
3. **等待启动完成**
4. **开始使用系统**

### 停止服务

1. **点击停止服务按钮**
2. **等待停止完成**
3. **可以关闭启动器**

## 常见问题

### Q1: 启动很慢怎么办？

**原因**：
- 首次启动需要安装依赖
- 系统资源不足
- 网络问题

**解决**：
1. 首次启动请耐心等待（30-60 秒）
2. 后续启动会更快（5-15 秒）
3. 查看日志了解进度

**诊断**：
```bash
python3 diagnose.py
```

### Q2: 页面加载慢怎么办？

**✅ 此问题已解决！**

**之前的问题**：
- 页面使用外部 CDN (cdn.jsdelivr.net) 加载 Bootstrap 资源
- 如果网络慢或 CDN 访问受限，页面会一直加载

**当前状态**：
- 所有资源已下载到本地 (src/ui/static/)
- 页面加载时间 < 200ms ⚡
- 不依赖外部网络，完全本地加载

**验证方法**：
```bash
python3 diagnose.py
```

**如果仍然慢**：

1. **运行诊断工具**
   ```bash
   python3 diagnose.py
   ```
   查看哪个组件响应慢

2. **查看详细报告**
   ```bash
   cat 性能优化报告.md
   ```

3. **重启服务**
   - 点击 `🔄 重启服务`

### Q3: 端口被占用怎么办？

**解决**：
1. 点击 `💪 清理端口` 按钮
2. 启动器会自动清理端口 8000
3. 然后重新启动服务

### Q4: 环境检查失败怎么办？

**检查项**：
- Python 版本（需要 3.9+）
- Gemini CLI（需要安装）
- 虚拟环境（自动创建）

**解决**：
1. 升级 Python 到 3.9 或更高
2. 安装 Gemini CLI：
   ```bash
   npm install -g @google/generative-ai-cli
   ```

### Q5: 退出启动器后服务还在运行？

**说明**：
- 这是正常行为
- 启动器退出不会停止服务
- 服务继续在后台运行

**如需停止**：
1. 重新打开启动器
2. 点击 `🛑 停止服务`

## 性能优化建议

### 减少启动时间

1. **预先安装依赖**
   ```bash
   python3 -m venv venv
   source venv/bin/activate
   pip install -r requirements.txt
   ```

2. **保持虚拟环境**
   - 不要删除 `venv` 目录
   - 后续启动会快很多

### 改善页面加载速度

1. **等待完全启动**
   - 确保日志显示"服务启动成功"
   - 看到提示后再打开浏览器

2. **检查系统资源**
   - 关闭不必要的程序
   - 确保有足够的内存和 CPU

3. **使用诊断工具**
   ```bash
   python3 diagnose.py
   ```
