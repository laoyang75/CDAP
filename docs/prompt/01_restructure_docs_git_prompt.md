# Prompt 1：阶段一 - 目录重构 + 文档整理 + 推送 Git（可直接复制给AI执行）

你是资深重构工程师。当前项目可以正常运行，请在“尽量不改业务行为”的前提下，完成结构治理与版本治理。

## 项目背景
- 核心项目：`cdid-analysis-platform`
- 远程 Git 仓库：`https://github.com/laoyang75/CDAP.git`
- 当前仓库混有：核心代码、对外交付压缩包、历史遗留文件
- 本阶段只做结构和治理，不做功能重写

## 本阶段目标
1. 目录重构：按职责和生命周期整理目录
2. 文档整理：补齐重构文档与迁移记录
3. Git治理并推送：形成清晰提交历史并推送到远端

## 强约束（必须遵守）
- 保证当前可运行能力不被破坏
- 先盘点再迁移，先小步提交再合并
- 重命名/迁移优先保留历史（如 `git mv`）
- 不确定是否删除的内容先归档，不直接删
- 本阶段禁止大规模逻辑改写；若必须改代码，仅限路径/引用修复

## 你要执行的工作
1. 盘点并分类现有文件：保留、迁移、归档、候选删除
2. 给出目标目录结构（tree）并说明每层职责
3. 分步骤实施迁移（每步附命令、风险、回滚）
4. 整理重构文档并落盘
5. 配置并校验远程仓库，完成分支提交与推送

## 必须产出文件（落盘到 `docs/restructure/`）
- `inventory.md`：文件盘点与分类表
- `target-structure.md`：目标目录结构与设计原则
- `migration-plan.md`：迁移步骤、命令、风险、回滚
- `git-plan.md`：分支策略、提交序列、推送策略
- `execution-log.md`：实际执行记录（做了什么、结果如何）
- `verification-checklist.md`：重构后运行验证清单

## Git执行要求
- 校验远程：`git remote -v`
- 若未绑定：`git remote add origin https://github.com/laoyang75/CDAP.git`
- 推荐流程：从 `main` 拉 `refactor/restructure-docs` 分支执行
- 使用 Conventional Commits（`refactor:`, `chore:`, `docs:`）
- 输出“建议提交序列 + 实际提交记录 + 推送命令”
- 如果受权限限制无法 push，必须给出一键可执行的推送命令

## 输出格式（严格按此顺序）
1. 当前状态判断
2. 盘点分类表
3. 目标目录结构（tree）
4. 分步迁移方案
5. Git提交与推送计划
6. 风险与回滚
7. 验收清单与执行结果
8. 待确认项
